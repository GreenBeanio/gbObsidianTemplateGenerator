# Term Base class for Term classes

Term Base class for Term classes

## Active bindings

- `contents`:

  The contents of the `Term` The contents method (must be overridden by
  children)

## Methods

### Public methods

- [`Term$new()`](#method-Term-initialize)

- [`Term$clone()`](#method-Term-clone)

------------------------------------------------------------------------

### `Term$new()`

Initialize a new ObsidianNote object

#### Usage

    Term$new(contents)

#### Arguments

- `contents`:

  The contents of the `Term`

#### Returns

A new `Term` object

------------------------------------------------------------------------

### `Term$clone()`

The objects of this class are cloneable with this method.

#### Usage

    Term$clone(deep = FALSE)

#### Arguments

- `deep`:

  Whether to make a deep clone.
