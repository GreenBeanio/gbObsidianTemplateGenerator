# Obsidian Template Generator

This is a tool meant to generate missing daily note templates for my
Obsidian notes.

See the [Getting
Started](https://greenbeanio.github.io/gbObsidianTemplateGenerator/articles/Getting_Started.html)
for more information.

## Background

This package was created because I keep a daily journal inside of
Obsidian. I fell behind for a month or two and manually linking the
files after all that time is tedious. Instead I spent far more time than
it would take for me to manually do that on this package. It is not very
extensible, but I might revisit it if I’m bored. For now it works for
generating my daily planning/tracking note structure. This consists of
Yearly, Quarterly, Monthly, Weekly, and Daily Notes. Think of it akin to
a daily planner or journal.
